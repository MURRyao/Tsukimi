# Landing-page screenshots

The landing page is complete without screenshots, but real product images make the Shelf section more trustworthy.

## Recommended captures

`shelf.png` is the current product image used by the landing page. Add 2–3 more PNG or WebP files to this folder after testing the release build:

- `capture-area.png` — the area-selection overlay on a clean desktop.
- `settings.png` — the preferences window, preferably showing the shortcuts settings.

Capture at native Retina resolution and crop the images deliberately; a 1600–2400 px wide source works well. Do not include personal notifications, file names, API keys, or other sensitive content.

When adding more images, use paths such as `media/settings.png` in `../index.html` and keep meaningful `alt` text for each image.
